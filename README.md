# Мультимодальная 3D-сегментация объектов произвольной формы в системах измерения весогабаритных характеристик

Оформление: LaTeX-шаблон [sadekovlar/misis-article-latex](https://github.com/sadekovlar/misis-article-latex) (`misisarticle.cls`, LPPL 1.3c, без изменений).

## О работе

Предложен двухпотоковый метод сегментации разнотипных грузов (коробки, цилиндры, нестандартная тара) по совмещённым данным ToF и RGB для программно-аппаратного комплекса Garpix 3D Scan Visioner. Пространственные координаты облака точек и цвет кадра объединяются до сети и между потоками. PointNet++ выделяет границы сложного профиля, RandLA-Net удерживает вывод одной сцены в пределах 500 мс. Механизм самовнимания трансформера и отдельная двумерная сегментационная сеть не используются.

Схема метода:

1. Калибровка и проекция точек облака на кадр RGB, вектор точки `(x, y, z, R, G, B)`.
2. Поток PointNet++: иерархические локальные признаки границы.
3. Поток RandLA-Net: случайное прореживание и локальное агрегирование.
4. Слияние: `h = [h_pp ⊕ h_rl]`, затем MLP и softmax.

Метрики: mIoU (основная), F1-score, Precision, Recall, время инференса не более 500 мс. Данные: реальные сканы Visioner, синтетика Blender/CARLA, предобучение ShapeNet и ScanNet.
